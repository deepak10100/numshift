BUILT FOR CAREFUL EDITS

Everything you need
to shape your text.

Start with a quick replacement, then switch to advanced country and emoji workflows or extract text from a supported document.

01 / REPLACE

Simple text & number replacement

Enter what to find and what to use instead. The result updates live so you can review every change before copying or exporting.

02 / FORMAT

Preserve number separators

Number replacements retain the detected formatting marks—including spaces and Unicode punctuation—where possible.

03 / COUNTRY

Optional country detection

In Beast Mode, enable the country auto-detect option to group calling codes and assign country-specific replacements. Unknown codes can be assigned manually.

04 / EMOJI

Choose and place emojis

Select several emojis from the picker. Add them at sentence endings or after each detected number; replace emojis already in your text too.

05 / DOCUMENTS

Extract supported file content

Upload TXT, MD, CSV, JSON, HTML, PDF, DOCX or XLSX files up to 20 MB. Scanned PDFs can use English/Spanish OCR for up to 20 pages.

06 / EXPORT

Review before you export

Preview the updated result, then export to TXT, HTML or PDF. The current PDF export re-typesets text and does not preserve the source PDF's exact design.

PDF and emoji note: exported PDF layout is newly generated from extracted text; original page artwork and exact typography are not preserved. Some emoji characters may not render in the generated PDF.
