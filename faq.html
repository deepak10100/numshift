Frequently asked
questions.

Details on file formats, modes, privacy and export behavior.

Which file formats can I upload?

TXT, MD, CSV, JSON, HTML, PDF, DOCX and XLSX files up to 20 MB. Other formats are rejected with a clear error.

Can it read scanned or image-only PDFs?

When OCR tools are available on the extraction server, scanned PDF pages are recognized in English and Spanish, up to the first 20 pages. Low-quality scans, unusual fonts and complex layouts can lead to mistakes.

How does PDF title detection work?

The app checks PDF metadata first, then a recognizable heading, then a short meaningful first line. If it finds none, it uses the filename.

Does country auto-detection always show?

No. In Beast Mode, enable the Country auto-detect checkbox to reveal the country table. Country-specific replacements are part of Beast Mode.

Can I use multiple emojis?

Yes. Choose several in the emoji picker. In “After every number” placement, the selected emoji choices rotate across detected number formats.

Will the PDF export preserve the uploaded PDF's original layout?

Not currently. PDF export creates a new, text-based document from the edited content; it does not preserve original page graphics, exact typography or positioning. Emoji glyph support in the generated PDF is limited.

Where does the PDF go if Chrome blocks a direct download?

The app saves a workspace copy at exports/latest-export.pdf. Open the file from the workspace to view or download it.

Is my content stored?

Uploaded files are processed by the extraction server and are not intentionally retained. Replacement settings are session-only. An exported PDF remains in the workspace until removed.
